# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), а версии следуют Semantic Versioning.

## [0.1.0] - 2026-11-12

### Added

- Создано приложение Task Manager на React и TypeScript.
- Добавлена возможность добавления задач.
- Добавлена валидация пустых задач.
- Добавлены тесты на Vitest.
- Настроен ESLint.
- Настроен CI/CD через GitHub Actions.
- Добавлены GitHub Secrets и Environment Variables.
- Добавлена проверка на нескольких версиях Node.js.
- Настроен автоматический деплой на GitHub Pages.
